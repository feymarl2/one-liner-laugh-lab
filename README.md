One short funny line, the excuse a robot vacuum gives after eating a sock: it stares sharply at the corner of the room, as if plotting a coup.

## Run it

```sh
python3 main.py
```

`main.py` (Python 3.13, standard library only) writes the line to `/output/entry.txt`: UTF-8, 115 characters, byte-identical on every run.
